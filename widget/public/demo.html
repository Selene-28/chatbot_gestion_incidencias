Página de prueba del widget

Esta página simula el sitio web institucional de la FIIS-UNAC y sirve para validar la integración del Asistente Virtual del CTIC. Haga clic en la burbuja 💬 de la esquina inferior derecha para iniciar una conversación: puede registrar una incidencia, consultar el estado de un ticket, revisar las preguntas frecuentes o contactar con el personal de soporte. Si el bot no puede resolver la consulta, la conversación se transfiere a un agente humano del CTIC, cuyas respuestas llegan al chat en tiempo real.

Entorno de pruebas — las incidencias registradas aquí no corresponden al sistema de tickets de producción del CTIC.

Servicios tecnológicos atendidos

El asistente virtual brinda soporte de primer nivel sobre los servicios del CTIC:

  1. Correo institucional (@unac.edu.pe) y recuperación de contraseñas.
  2. Conectividad WiFi e Internet en el campus.
  3. Aula Virtual y plataformas académicas.
  4. Software institucional y licencias.
  5. Registro, consulta y escalamiento de incidencias técnicas.

Sobre el proyecto

Este chatbot forma parte del proyecto de tesis «Chatbot para la gestión de incidencias del CTIC de la FIIS — UNAC». El sistema combina flujos conversacionales guiados con recuperación de información sobre una base de conocimiento (RAG), registra las incidencias en un servicio de tickets con contratos idénticos a los del sistema institucional, y permite la transferencia de la conversación a un agente humano cuando el bot no puede resolver la consulta.

Cómo se integra en un sitio web

Basta con agregar una línea antes de cerrar </body>:

<script src="https://ctic.unac.edu.pe/widget/widget.js"
        data-api="https://ctic.unac.edu.pe/api" defer></script>

El atributo data-api indica la URL base de la API del chatbot. El widget no requiere ninguna dependencia adicional y carga sus propios estilos.
